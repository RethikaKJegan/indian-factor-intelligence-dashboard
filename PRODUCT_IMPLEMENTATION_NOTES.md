# Product Implementation Notes

This project has started moving from a research dashboard to an end-user monthly positional trading assistant.

## Implemented In This Slice

- Simplified main navigation:
  - Command Center
  - Trade Plan
  - Final Portfolio
  - Stock Inspector
  - Performance & Trust
  - Advanced Research
  - Admin Status
- Local browser holdings input using `localStorage`.
- Personalized trade quantity calculation:
  - current user quantity
  - model target quantity
  - final executable trade quantity
  - estimated trade value
- Daily EOD risk overlay:
  - Normal: execute full plan
  - Caution: stagger buys
  - Danger: pause new buys
  - Extreme: defensive execution
- Trade Plan CSV export and copy-trades button.
- Advanced Research wrapper that preserves the original detailed dashboards.
- Performance & Trust page with mandatory caveats.

## Current Architecture

The UI still reads static generated JSON from:

```text
public/data/*.json
```

The app is currently frontend-only. User holdings are stored locally in the browser, not in a backend account.

This is intentional for the first functional slice. Backend persistence can be added later.

## Existing EOD Automation

The project already contains:

```text
scripts/daily_eod_refresh.py
scripts/run_langgraph_pipeline.py
scripts/run_daily_eod_pipeline.ps1
.github/workflows/daily-eod-refresh.yml
EXTERNAL_CRON_SETUP.md
```

The documented production automation is:

```text
cron-job.org
  -> GitHub repository_dispatch
  -> GitHub Actions daily EOD workflow
  -> Python EOD/model pipeline
  -> commit updated public/data/*.json
  -> Vercel auto-redeploy
```

Vercel cron is not required for the current architecture. If the project later moves to server/API routes, add secured cron endpoints with `CRON_SECRET`.

## Important Product Rules

- The model universe is currently 189 usable stocks.
- The 11 excluded Nifty 200 symbols must remain excluded until a recovery pipeline proves enough reliable history exists.
- News is supporting evidence only.
- The LLM must only explain structured model/risk outputs; it must not decide trades.
- The Performance & Trust page must show caveats and benchmark failures honestly.
- This is decision support, not blind auto-trading.
